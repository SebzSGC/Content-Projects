# Carpeta de Recursos Adjuntos

> [!abstract] En pocas palabras
> Directorio reservado para imágenes, diagramas exportados en PNG/SVG, audios de muestra o documentos PDF vinculados dentro de las notas de documentación.

---

## 📁 Uso de esta carpeta
Al pegar o arrastrar imágenes o archivos multimedia en notas de Obsidian, se almacenan automáticamente en este directorio y se referencian mediante sintaxis de incrustación de imagen estándar de Obsidian.
